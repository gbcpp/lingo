# Lingo

独立实现的 macOS / Windows 翻译桌面应用，参考 Bob 的快捷键使用流程，不使用 Bob 源码或 macOS 专有翻译插件。

## 已实现

- 百度通用文本翻译：自动识别语言、中英日韩法德西俄互译。
- Google Cloud Translation Basic v2：使用官方 API，需要自己的 Key 和可访问该 API 的网络。
- 默认「自动中英互译」：英文较多译中文，中文较多译英文，适用于输入、划词、剪贴板和截图 OCR。按汉字／英文字母数比较，数字与符号不计；数量相等或没有中英文字时默认译中文。手动目标语言优先，手动选择中文原文时自动译英文，其他原文语言自动译中文。
- 默认 Enter 翻译、Command+Enter 换行（Windows 使用 Ctrl+Enter）；翻译按钮右侧下拉菜单可切换为组合键翻译、Enter 换行，保存后重启仍生效。中文输入法确认候选词时不会触发翻译。
- 输入翻译、剪贴板翻译、全局快捷键划词翻译；macOS 优先读取辅助功能选区，不支持时等待修饰键释放后复制，期间切换应用会取消；原文与译文分别提供一键复制。
- 程序员模式：翻译前将注释标记、下划线、连字符等标点与符号替换为空格，保留文字、数字与换行；默认关闭，可在原文栏或偏好设置中切换并保存。
- 开机自动启动：默认关闭，可在「偏好设置 → 常规」配置，登录后仅常驻菜单栏／托盘。
- 截图框选翻译：支持任意屏幕及跨屏选区，显示 20 × 20 纯黑十字光标与 1 像素黑色选区边框，无白色描边和彩色修饰，不显示变暗遮罩，Tesseract 在本机识别中英文。
- 划词／剪贴板没有文字、截图识别为空或取消截图时，不弹出翻译窗口；OCR 在后台完成，有文字才展示结果。
- 翻译后自动朗读原文，可设置开关、系统语音和语速；支持手动朗读译文、停止。
- 原文注音：英文显示美式 IPA 音标，中文显示带声调的拼音；无需联网或额外 API。
- 紧凑翻译浮窗：宽 500 像素，原文和译文增多时自动增高，短文恢复紧凑高度；超出屏幕的内容可滚动。
- 窗口失去焦点或按 Esc 自动隐藏；菜单栏／系统托盘常驻，可通过快捷键或托盘再次打开。
- 四项全局快捷键均可在设置中修改，支持仅 Option（Windows 为 Alt）作为修饰键、冲突检测和保存失败回滚。
- macOS 默认隐藏程序坞图标，在「偏好设置 → 程序坞」中可开启；保存立即生效，重启后保留。应用与菜单栏使用折页图标；菜单栏图标宽 18 像素。
- API 凭据经 Electron safeStorage 的系统密钥机制加密后保存在本机；不保存翻译历史。

金山整句翻译尚未接入：当前确认的公开文档是词典查词 API，不将非公开网页接口当作稳定 API。如果获得金山的正式翻译 API 文档和凭据，可添加对应服务。

## 启动

需要 Node.js 22 或更新版本以及 npm。首次安装需要联网下载 Electron 和 OCR 模型。

```sh
npm ci
npm start
```

若 Electron 运行时下载失败，在网络恢复后运行：

```sh
npx install-electron --no
npm start
```

在「偏好设置」中填写百度 APP ID 与密钥，保存后即可翻译。密钥不要提交至源码仓库，也不需要发送给其他人。已保存密钥的输入框留空表示保留，勾选删除表示移除。

### 百度

1. 打开 [百度翻译开放平台](https://api.fanyi.baidu.com/)，完成所需账号认证。
2. 开通「通用文本翻译」服务，获取 APP ID 与密钥。
3. 在本应用设置中填写并保存。服务配额、计费、IP 限制以你的百度账户为准。

接口为 `https://fanyi-api.baidu.com/api/trans/vip/translate`，使用 HTTPS POST 和官方 MD5 签名方案。为兼容百度文本限制，单次输入限制为 6000 UTF-8 字节；不自动拆分长文，避免隐含的额外调用。

### Google

在 Google Cloud 项目中启用 Cloud Translation API，完成所需计费配置，并创建适用于 Cloud Translation Basic v2 的 API Key。把 Key 填入设置。国内网络可能无法连接 Google API；应用不提供网络代理服务。

### 朗读

- macOS 使用系统 `say`，Windows 使用 Windows PowerShell 和 `System.Speech`。
- 自动匹配优先选择常规朗读语音，避免按列表顺序选中角色或音效声音。macOS 英文优先 Samantha，普通话优先 Tingting（需已安装），明确地区时优先匹配地区。手选语音只在语言匹配时使用，其他语言自动匹配。
- 缺少语言语音时会提示，不会偷偷切换成另一种语言。Windows 的部分现代 Narrator 语音不对 `System.Speech` 开放，以应用实际列出的语音为准。
- 自动朗读默认关闭，开启后固定朗读原文，语言跟随原文。升级时旧的「自动朗读译文」配置迁移为原文，保留原开关状态和语速。手动「朗读译文」按钮继续读译文。
- 英文音标来自随应用打包的 [ipa-dict 美式词典](https://github.com/open-dict-data/ipa-dict)，逐词列出词典读音，保留多个读法；不是整句连读转写，也不自动判断同形异音词在句中的读法。未收录词明确标记。
- 中文拼音使用 [pinyin-pro](https://github.com/zh-lx/pinyin-pro) 在本机生成，包含声调和常见多音词匹配；人名、生僻词的读音仍可能需要核对。中英文注音不受翻译 API 是否配置影响。

## 快捷键

macOS 使用 `Command + Option`，Windows 使用 `Ctrl + Alt`，再加以下字母：

- `A`：显示输入窗口。
- `D`：翻译当前选中文字。
- `C`：翻译剪贴板文字。
- `S`：框选截图并 OCR 翻译。

窗口内默认 `Enter` 翻译、`Command/Ctrl + Enter` 换行，可在翻译按钮旁切换；截图时 `Esc` 或右键取消。在「偏好设置 → 快捷键」中选择每项功能的修饰键与按键，点击「保存设置」立即生效，重启后保留。修饰键可选单独 Option / Alt，例如 `Option + D`；支持字母、数字、F1–F12 和空格；「恢复默认」需保存后生效。重复组合或系统注册失败会提示并保留旧设置。失焦隐藏不会清空翻译内容；通过托盘打开窗口可以继续查看。

### macOS 权限

- 划词功能需要「系统设置 → 隐私与安全性 → 辅助功能」，可能还需要允许控制 System Events 的自动化权限。
- 截图需要「屏幕录制」或「屏幕与系统音频录制」权限。授权后可能需要退出并重开应用。
- 开发模式中系统可能显示 Electron；打包后显示 Lingo。

### 开机自动启动

安装打包后的应用后，在「偏好设置 → 常规」勾选「开机自动启动」并保存。macOS 应先将应用移入「应用程序」，Windows 应运行安装程序；避免将启动项指向临时目录。关闭同一选项并保存可移除启动项。程序读取系统实际状态，不会在每次启动时强制覆盖用户在系统中的禁用操作。

如 macOS 返回需要批准，设置页会提示前往系统登录项中允许。系统未接受设置时显示错误，不会假报保存成功。未签名、公证的 macOS 开发包可能无法注册登录项，参见 [Electron 登录项说明](https://www.electronjs.org/docs/latest/api/app#appsetloginitemsettingssettings-macos-windows)。开发模式不注册 Electron 本身为启动项。

### 划词和截图边界

划词通过模拟复制读取选区，不持续监视剪贴板。目标应用须支持复制；密码框、保护内容、Windows 更高权限应用等可能不可用。常见的文本、HTML、RTF、图片剪贴板内容会尽量恢复，应用专有格式未承诺完整恢复。操作期间不要同时复制其他内容。

截图启动后，所有屏幕使用透明鼠标捕获层，显示十字光标与选区边框，不冻结或覆盖屏幕画面。按住左键在任意屏幕或跨屏拖动，松开后才读取屏幕并裁剪；选区边框不会进入截图。Esc 或右键取消。跨屏图片按实际缩放比例裁剪并拼接，屏幕布局中的空隙填白。极大选区会限制输出尺寸以控制内存；不支持滚动截图。框选时屏幕布局变化会取消本次截图，需重新选择。OCR 模型随应用打包，无需首次运行时下载。图片不发给翻译服务；识别出的文字会立即发给你选择的翻译服务。OCR 可能误识别，译前原文显示在输入框，可修改后重新翻译。

## 构建

```sh
npm test
npm run smoke
npm run dist:mac -- --arm64 --publish never
```

macOS Intel 版本将 `--arm64` 改为 `--x64`。Windows 上执行：

```sh
npm ci
npm test
npm run smoke
npm run dist:win -- --x64 --publish never
```

产物位于 `release/`。已提供 `.github/workflows/build.yml`，支持手动触发或推送 `v*` 标签时，在 macOS 和 Windows runner 分别测试并构建。

正式对外分发前需要自己的 Apple Developer ID 签名、公证配置；Windows 可配置代码签名证书。开发构建不等于经过签名、公证的正式发行版，操作系统可能提示来源未验证。请勿为运行软件关闭系统整体安全保护。

## 验证范围

`npm test` 验证 API 签名、语言映射、网络错误、取消、密钥存储、朗读取消、快捷键冲突回滚和旧配置迁移。存储测试使用测试加密器，不能代替操作系统密钥服务验证。

`npm run smoke` 启动真实 Electron 窗口，验证缺少凭据提示、界面翻译流程、显示安全性、过期结果丢弃、自动朗读调用、快捷键设置、窗口自动伸缩及失焦隐藏，并使用真实离线中英文 OCR 引擎识别测试图片。翻译响应和语音播放在 UI 测试中被模拟，避免调用付费服务或播放声音。预览图中的译文为测试样例。

`npm run smoke:capture` 使用真实 Electron 选区窗口与合成的双屏快照，检查透明窗口、自定义十字光标、跨屏选区边框与内部透明像素、松开后截图、混合缩放拼接、第二屏截图、取消／失败清理、Option 组合保存、启动项保存回滚和 macOS 程序坞实际显隐；OCR、系统登录项及系统加密器使用测试替身，不调用付费服务、不读取真实屏幕。

没有 API 凭据时不能完成真实百度／Google 联调。全局选区、系统截屏权限、真实扬声器播放仍需要在对应操作系统手工验收：

1. 填写自己的 API 凭据，翻译一段文字，确认真实结果。
2. 开启自动朗读，分别输入中英文，确认读的是原文、原文下方显示音标／拼音；调整语速并重启确认设置保留。
3. 在浏览器／文本编辑器选中内容，按划词快捷键，确认翻译和原剪贴板恢复。
4. 截取一块中英文文字区域，确认 OCR 结果；按 Esc 验证截图取消。
5. 连续发起翻译、编辑原文和点击取消，确认旧结果不会覆盖新输入。
