偏好设置

快捷键

选择修饰键与字母、数字或功能键，保存后立即生效。组合不能重复或被其他应用占用。

常规

登录系统后自动启动并常驻菜单栏／托盘，不弹出翻译窗口。

程序员模式在翻译前将 //、/*、-、_ 等标点与符号替换为空格，保留文字、数字和换行。

程序坞

默认仅在菜单栏常驻。修改后保存即可生效。

翻译服务

使用你自己的 API 凭据。调用额度与费用由服务商账户决定。

百度 · 通用文本翻译
Google · Cloud Translation Basic v2

金山：暂未接入整句翻译。目前确认的公开接口是词典查词，不能替代通用翻译。

朗读

使用本机系统语音，自动优先选择常规朗读声音。手选语音仅用于匹配的语言，其他语言自动匹配。

自动朗读固定使用原文。英文显示美式音标，中文显示带声调的拼音。

使用与权限

划词：先在其他应用选中文字，再按快捷键。需要应用支持复制；常见文字、图片剪贴板会尽量恢复，特殊格式可能无法完整保留。

截图：可在任意屏幕或跨屏拖动框选，显示十字光标与选区边框，不显示变暗遮罩；Esc 或右键取消。本机识别中英文，识别文字随后发送至所选服务翻译。

关闭窗口后留在菜单栏／托盘，使用菜单中的“退出”结束运行。不保存翻译历史。

凭据由系统密钥机制加密后存于本机
